XCAR — учёт аренды автомобилей
================================

В архиве 5 файлов:
  index.html      — само приложение
  manifest.json    — настройки PWA (иконка, название)
  sw.js            — офлайн-режим
  icon-192.png     — иконка
  icon-512.png     — иконка

ВАЖНО: просто открыть index.html с телефона (двойным нажатием на файл)
НЕ ПОЛУЧИТСЯ установить как приложение — Chrome требует, чтобы сайт был
на HTTPS. Это ограничение браузера, а не файла.

Как установить на Android за 5 минут (бесплатно, через GitHub Pages):

1. Зайдите на github.com и создайте бесплатный аккаунт (если его ещё нет).

2. Нажмите "New repository" (Новый репозиторий).
   - Название: любое, например "xcar"
   - Поставьте галочку "Public"
   - Нажмите "Create repository"

3. На странице репозитория нажмите "uploading an existing file"
   (или "Add file" → "Upload files").

4. Перетащите туда все 5 файлов из этого архива (index.html, manifest.json,
   sw.js, icon-192.png, icon-512.png) и нажмите "Commit changes".

5. Зайдите в Settings (Настройки) репозитория → Pages (слева в меню).
   В разделе "Branch" выберите "main" и папку "/ (root)", нажмите Save.

6. Подождите 1-2 минуты. GitHub покажет вам ссылку вида:
   https://ваш-логин.github.io/xcar/

7. Откройте эту ссылку в Chrome на телефоне (Android).

8. Нажмите на три точки (⋮) в правом верхнем углу → "Установить приложение"
   (или Chrome сам покажет баннер снизу "Добавить XCAR на главный экран").

Готово! Иконка появится на главном экране и будет открываться как
отдельное приложение, без адресной строки браузера. Все данные
хранятся прямо на телефоне (localStorage), интернет для работы не нужен —
только для первой загрузки и обновлений.

Другие варианты бесплатного HTTPS-хостинга, если не хотите GitHub:
  - Netlify Drop: app.netlify.com/drop — просто перетащите папку с файлами
  - Vercel: vercel.com
